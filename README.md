## Project Description

**Labbayk** (لبيك) is a system that activates qualified medical professionals among Hajj pilgrims as emergency first responders, integrated with the Nusuk app, to reduce emergency response time during peak crowding in Mina.

The system dispatches nearby medically-qualified pilgrims to emergencies before ambulances arrive, leveraging the unique reality that thousands of doctors, nurses, and paramedics perform Hajj annually and are already present at the scene.
